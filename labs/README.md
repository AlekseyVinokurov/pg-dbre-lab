# Labs

Focused PostgreSQL experiments are stored here.

Each lab should be reproducible and should separate observation from conclusion. Do not commit a result as "optimized" without measurements that show what changed and why.

2. Query planner & joins

6. Memory, WAL & Linux
7. Operations, recovery & replication
